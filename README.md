# Photofy

Sistema de fotos e reels ao vivo para eventos de marca do Clube Condor. Participantes enviam fotos/reels via QR Code sem login; conteúdo aprovado por moderação humana alimenta um slideshow no telão (pareado por dispositivo) e uma galeria pública permanente.
